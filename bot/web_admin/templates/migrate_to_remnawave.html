Миграция в Remnawave

Создание пользователей в Remnawave по данным из вашей БД.

Как это работает

  • Для каждого пользователя (любой статус подписки) создаётся аккаунт в Remnawave.
  • Username — из email (до @), иначе паттерн tg{user_id}.
  • Один UUID для xui_client_uuid, remnawave_short_uuid, remnawave_user_uuid.
  • Дни подписки из даты окончания (минимум 1 день для истёкших).
  • Уже существующие в Remnawave пропускаются; пустой UUID — пропуск.
