Xray JSON

Шаблон конфигурации Xray для клиентов по подписке (формат 3X-UI / SUBPAGE). В режиме «По серверам» шаблон — массив конфигов; у каждого элемента поле remarks становится отдельным профилем в приложении (например 🇳🇱 Нидерланды).

Поведение по провайдеру

3X-UI
Шаблон из настроек ниже

JSON собирается из шаблона; плейсхолдеры [UUID] и [EndDate] подставляются при выдаче через SUBPAGE.

Нужны работающий SUBPAGE и заполненный шаблон.
Remnawave
Готовый JSON от Remnawave

Конфиг запрашивается по /api/sub/{short_uuid}/json. Шаблон ниже не используется.

Серверы 3X-UI в такой конфиг не включаются.
Связка 3X-UI + Remnawave: бот запрашивает JSON у Remnawave — шаблон на этой странице не применяется.
