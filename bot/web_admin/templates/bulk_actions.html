Массовые действия

Операции над группами клиентов: удаление давно истёкших, компенсация активным подпискам, повторная выдача по failed-платежам и очистка базы устройств.

Внимание

  • Удаление необратимо: клиент исчезнет из БД и Remnawave (как кнопка «Удалить» в разделе «Клиенты»).
  • Компенсация продлевает только дни у клиентов с активной подпиской, без уведомлений в Telegram.
  • «Пустые UUID» — записи без клиента в Remnawave; удаляются только из БД бота.
  • «Failed-платежи» — повторная выдача подписки или докупки GB по оплаченным, но не выполненным платежам (без лимита устройств).
  • «Очистка устройств» — полное удаление всех записей из devices.db; необратимо.
  • Доступно только администратору.

Обработать failed-платежи

Ищет платежи со статусом «Неуспешно» (оплата прошла, выдача не выполнилась) и повторно выдаёт продление подписки или докупку GB по данным из metadata платежа. Лимит устройств не обрабатывается.

Если вы уже вручную продлили клиента или добавили трафик, а платёж остался failed — повторная обработка начислит ещё раз. Перед запуском проверьте список failed-платежей. Клиентам уведомления не отправляются.

Очистка устройств клиентов

Полностью очищает базу devices.db (таблица привязок HWID/OS к подпискам). Используется для лимита устройств, отчётов о нарушителях и раздела «Мои устройства».

Все устройства, привязанные к клиентам, исчезнут из базы.

Список начнёт формироваться заново при следующих подключениях клиентов к сервису. Лимиты устройств временно «обнулятся», пока клиенты снова не зайдут в подписку.

Делайте очистку только если знаете, зачем она вам нужна — действие необратимо.
