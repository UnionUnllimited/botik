Лимит устройств

Платный апгрейд числа устройств без сброса срока подписки. Цены в RUB ₽.

{# === Info: how it works === #}

Как это работает: при покупке апгрейда меняется только значение users.limit_ip в БД. Сроки подписки не уменьшаются — клиент платит пропорционально оставшимся дням.

Формула: (новый_лимит − старый) × осталось_дней × цена_за_слот_в_день. Если результат меньше «минимального чека» — сумма округляется вверх.

{# Critical warning #}

Важно! Тарифная линейка должна строго соответствовать максимальному лимиту.

Для каждого limit_ip от 1 до {{ settings.device_upgrade_max_limit or 'N' }} у вас должен существовать активный тариф продления подписки. Иначе после расширения лимита клиент не сможет продлить подписку — список тарифов будет пуст (продление фильтруется строго по текущему limit_ip).
