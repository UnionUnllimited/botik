Обновление и хранилище
Круг спрашивает источники по метке версии: неизменившиеся отвечают без тела, поэтому частота почти ничего не стоит. Пересборка идёт только когда хоть один изменился.
Копия списков в объектном хранилище. Нужна на случай, когда наш сервер перезапускается выкатом, а парк приходит за обновлением. Пусто — выкладка выключена, списки всё равно отдаются с нашего домена.
