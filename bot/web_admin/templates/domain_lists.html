Обновление
Выключенный авторежим не отменяет кнопку «Собрать сейчас» — она собирает списки напрямую.
{# Списком, а не полем: осмысленных значений десяток, а в поле вводят «0» — и это круг без пауз по чужому GitHub, который отвечает на такое запретом. #}
Круг спрашивает источники по метке версии: неизменившиеся отвечают без тела, поэтому частота почти ничего не стоит. Пересборка идёт только когда хоть один изменился.
