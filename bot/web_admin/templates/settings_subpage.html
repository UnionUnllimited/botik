Настройки Subpage
Управление контентом страницы подписки (subpage) без правки .env на сервере. Subpage подхватывает эти настройки при рестарте через xuiweb.
{# Подсказка про активацию + рестарт #}
Subpage: API_CUSTOM_SETTINGS=true + рестарт. Заглушки подписки (блокировка / лимит / срок) — сразу, без рестарта.

Отображается в Profile-Title и заголовках.
Ссылка «веб-страница профиля» в приложении. Поддерживает плейсхолдеры [UUID], [TelegramID], [Email], [REGTYPE]. Например https://sub.example.com/sub/[UUID]/info — откроет info-страницу конкретного клиента. Можно указать и свой произвольный URL.
Рекомендуемые: 1, 2, 3, 6, 12, 24.
Жёсткий лимит 200 символов для шаблона. Плейсхолдеры [Email], [TelegramID], [REGTYPE] — например 🪪 Ваш ID: [TelegramID].
[Email] [TelegramID] [REGTYPE]
В начало имени сервера в панели: [PC], [MOBILE], [ROUTER], [TV] — можно несколько. Без меток сервер для всех. У кого нет X-Device-OS — все сервера. Рестарт subpage после сохранения.
Если у пользователя limit_ip исчерпан и приходит запрос с новым HWID — отдаём заглушку «Превышен лимит устройств». Применяется сразу после сохранения, без рестарта xuiweb.

{# ── Таб 3: Заголовки ───────────────────────────────────────── #}
Эти HTTP-заголовки добавляются в ответ на запрос подписки от VPN-приложений (равноценно переменным RESP_HEADER_* в .env). В имени можно использовать как _, так и - — мы автоматически нормализуем (hide_settings → hide-settings). В значениях: [Email], [TelegramID], [UUID], [REGTYPE] (TG / SITE). Перенос строки: \n в тексте (для многострочного announce и др.).
[Email] [TelegramID] [UUID] [REGTYPE]
Примеры
providerid — ID провайдера в Happ (привязка подписки к вашему аккаунту).
hide-settings = 1 — скрыть просмотр конфигов от пользователя.
profile-update-interval — переопределить интервал обновления для приложения.
