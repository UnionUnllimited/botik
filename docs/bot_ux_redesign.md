# Редизайн интерфейса бота Titan Routers

Основание: бриф `D:/ghjvn/dsa.txt` (принципы референса Atlanta Routers) +
фактические экраны из кода (`bot/src/router_catalog.py`, `bot/src/shop_texts.py`,
`bot/main.py`, `bot/button_registry.py`). Логика и переходы не меняются —
только подача. Все `callback_data` ниже существующие; новые помечены
**(новый callback)**.

Механика баннеров: бот правит экраны через `edit_text`, поэтому баннер — это
превью ссылки (`LinkPreviewOptions`, как уже сделано для фото товара в
`card_preview()`, `router_catalog.py:213`), а не отдельное фото-сообщение.
По принципу референса баннеры ставим только на две «обложки» — главное меню и
карточку товара. Остальным экранам баннер не нужен: он ест высоту экрана и
превращает навигацию в листание картинок.

## 2. Мой роутер

**Текст (активирован, на связи):**

```html
<b>Мой роутер</b>
✓ На связи · подписка до <b>{expiry_date}</b>

{model_human} · в сети: {clients} устр.
Трафик: ↓ {rx} · ↑ {tx}
MAC: <tg-spoiler><code>{mac}</code></tg-spoiler>
```

Правила: `{model_human}` — человекочитаемое имя («ZBT Z8103AX», «Cudy
TR3000»), никогда не сырой board-id. Нет данных по трафику или клиентам —
строки нет целиком. Аптайм и URL админки с экрана убраны (админка остаётся
кнопкой). Подписка истекла — вторая строка: `⚠ Подписка закончилась {date}`.

**Текст (на связи, подписки нет):**

```html
<b>Мой роутер</b>
○ На связи · подписки нет
```

(про «оплатили — включится в минуты» и «второму роутеру нужна своя
подписка»).

**Текст (ещё не выходил на связь):**

Включите роутер и подключите интернет-кабель — дальше всё настроится само.

## Дизайн-система: токены

| Токен | Значение |
| --- | --- |
| Градиент баннеров | #0B1220 → #1E3A5F, диагональ 135° |
| Акцент | #4FC3F7 (цены, глифы на баннерах) |
| Текст на баннере | #FFFFFF, вторичный #9FB3C8 |
| Соотношение баннера | 2:1 (1280×640), подключение через превью ссылки |
| Глифы статуса | ✓ готово/активно · ○ ожидание/офлайн · • новое · ▸ в работе/в пути · ✕ отменено/нет · ↩ возврат · ⚠ требует внимания |
| Глифы действий | ↻ обновить/продлить · ↓ ↑ трафик · ‹ назад |
| Разметка | `<b>` — заголовок экрана и итог; `<code>` — ID, MAC, номера, трек; `<blockquote>` — одна ключевая выгода; `<tg-spoiler>` — MAC |
| Правило экрана | заголовок → строка статуса → ≤3 строки текста → клавиатура; пустых полей нет |
| Правило клавиатуры | ≤7 кнопок, ≤2 в ряд, подпись ≤22 символов; главные — во всю ширину сверху, пары — ниже, «‹ В меню» — всегда последняя |
| Термины | роутер (не «устройство»), подписка, заказ, срок подписки (не «тариф» в текстах клиенту) |
| Тон | спокойный, без восклицаний и канцелярита; глагол в начале действия («Выберите срок», «Нажмите на ID») |

## Чеклист внедрения (по приоритету)

1. **Человекочитаемые имена моделей** — словарь board-id → название
   («zbtlink,zbt-z8103ax-c» → «ZBT Z8103AX», «cudy,tr3000-v1» → «Cudy
   TR3000») + fallback-приведение для незнакомых плат; применить в
   `my_router_text()` и в подписях кнопок заказов. Единственный пункт,
   который чинит реальную утечку технических данных на экран.
2. **Единые статусы** — заменить `STATUS_LABELS` (`router_catalog.py:46-56`)
   на таблицу выше; используется всеми экранами сразу.
3. **«Мой роутер»** — компактный шаблон, скрытие пустых строк, MAC под
   `<tg-spoiler>`, новый экран «Почему нет подписки?»
   (`shop_why_no_sub:{id}`) с текущими текстами `text_my_router_*`.
4. **«Мои заказы»** — убрать текстовый список-дубль, подписи кнопок
   `#{id} {модель} · {глиф}`, свёртка отменённых (`shop_orders_all`).
5. **Заголовки заказов** — «Заказ #{id} — {модель}» в карточке, `R-…` вниз
   в `<code>` (`order_text()`, `router_catalog.py:567`).
6. **Главное меню** — новый порядок рядов через настройку `main_menu_layout`
   и текст через `text_welcome_message` — правится в админке без деплоя.
7. **Карточка товара** — цена в заголовок, `<blockquote>`-выгода (заполнить
   поле в админке для каждого товара), статусы наличия глифами.
8. **Подписи кнопок** — снять эмодзи через переопределения в
   `button_registry`/настройках (без деплоя), добавить глифы ↻ и ‹.
9. **Баннеры** — отрисовать 2 изображения (обложка меню, шаблон карточки
   товара), захостить, подключить превью-ссылкой по механизму
   `card_preview()`; для главного меню — добавить тот же механизм.

Пункты 6 и 8 — чистые настройки в БД, можно включить сегодня. Пункты 1–5 —
правки кода в `bot/src/router_catalog.py` (+ словарь моделей). Пункт 9
требует дизайнера/генерации изображений и хостинга.
